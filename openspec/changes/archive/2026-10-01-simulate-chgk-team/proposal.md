## Why

Нужен демонстрационный проект для резюме, который показывает многоагентную оркестрацию на LangGraph и langchain-gigachat через понятный зрителю сценарий: шесть игроков обсуждают настоящий вопрос ЧГК за минуту. Ценность проекта — в наблюдаемом взаимодействии разных ролей, проверке версий и измеримой работе с вопросами, а не только в получении одного ответа модели.

## What Changes

- Веб-страница на NiceGUI с вводом вопроса, шестью игроками, минутным таймером, последовательными репликами, версиями и финальным ответом.
- Граф с шестью отдельными агентами: капитан, генератор идей, два эрудита, логик и интуит. Этот состав выбран пользователем; у каждого игрока свой промпт, сильные и слабые темы.
- Общее состояние обсуждения: вопрос, история реплик, версии, аргументы и возражения, указания капитана. Игроки реагируют на предыдущие реплики.
- Капитан управляет очередностью, возвращает обсуждение к условиям вопроса, оценивает версии и выбирает отвечающего. Короткие содержательные реплики позволяют следить за обсуждением.
- Реальная минута от принятия сессии сервером, включая подготовку финального ответа; ограничение времени вызовов и честное отображение незавершённого ответа при сбое провайдера.
- Ограниченный поиск фактов эрудитами через бесплатный публичный Wikipedia/MediaWiki API со ссылками на источники и работой без поиска при сетевом сбое.
- Тестируемые адаптеры модели и поиска, демонстрационный режим без ключей, экспорт обсуждения и отдельный прогон на вопросах с известными ответами.

## Capabilities

### New Capabilities

- `team-discussion`: агенты, общая память, управление очередностью, минутный бюджет, выбор ответа и воспроизводимая оценка качества.
- `live-game-interface`: запуск сессии, события обсуждения, таймер, отображение игроков и версий, переподключение и экспорт.
- `knowledge-search`: ограниченный поиск эрудитов, происхождение фактов, сетевые ограничения и деградация при ошибках.

### Modified Capabilities

Нет: в проекте отсутствуют существующие спецификации и прикладная реализация.

## Impact

- Сейчас репозиторий содержит только `main.py` с Hello World, пустой README и `pyproject.toml` без зависимостей; Python проекта — 3.13. Приложение, API и тесты добавляются с нуля.
- Предлагаемые зависимости: LangGraph, langchain-gigachat, NiceGUI с FastAPI/Uvicorn, Pydantic, HTTPX; pytest и асинхронные тестовые инструменты для разработки. Веб-интерфейс — Python-компоненты NiceGUI и CSS, обновления через штатный WebSocket NiceGUI, без отдельной frontend-сборки. JSON API и SSE остаются для внешних клиентов и проверок.
- Потребуются серверные настройки GigaChat и доступ к публичному API поиска. Работа в реальном режиме зависит от задержек, тарифов и ограничений провайдера.
- Первая версия рассчитана на локальный запуск одним процессом; публичное размещение, аккаунты, распределённое хранение, обучение моделей и импорт базы вопросов за рамками изменения.
