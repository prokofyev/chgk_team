# knowledge-search Specification

## Purpose

Позволить эрудитам проверять отдельные факты через бесплатный публичный поиск, показывая происхождение информации и сохраняя минутный бюджет команды.

## Requirements

### Requirement: Scholar initiated bounded search
Только два эрудита SHALL иметь доступ к поиску. Поиск SHALL выполняться по конкретному запросу игрока, максимум два поиска на сессию, с максимум тремя результатами на запрос. После 45 секунд от старта новые поиски SHALL не запускаться. Отключённый поиск SHALL не мешать обсуждению на основе знаний модели.

#### Scenario: Scholar checks a fact
- **WHEN** эрудит запрашивает поиск до ограничения времени и остаётся лимит
- **THEN** запрос выполняется и его результаты доступны эрудиту для реплики и остальной команде в принятом состоянии

#### Scenario: Search budget exhausted
- **WHEN** эрудит запрашивает третий поиск либо новый поиск после 45 секунд
- **THEN** поиск не выполняется и игрок получает явное уведомление об ограничении

### Requirement: Free sources and provenance
Поиск SHALL работать через бесплатный публичный Wikipedia/MediaWiki API без отдельного платного ключа. Каждый найденный источник SHALL иметь заголовок, URL и короткий фрагмент. Подтверждение внешним источником SHALL ссылаться только на реально полученный результат; сведения из памяти модели SHALL не обозначаться как проверенные поиском.

#### Scenario: Evidence from a retrieved source
- **WHEN** реплика использует полученный источник как подтверждение факта
- **THEN** зритель и экспорт получают ссылку на этот источник, а неподтверждённые сведения остаются версиями

### Requirement: Search failure preserves the game
Каждый поиск SHALL иметь таймаут не более трёх секунд и учитывать общий дедлайн. Сетевой сбой, ограничение сервиса, пустая выдача или отключение поиска SHALL приводить к продолжению обсуждения без подтверждения факта. Ошибка поиска SHALL не превращаться в выдуманный источник.

#### Scenario: Source API unavailable
- **WHEN** публичный API не отвечает до таймаута
- **THEN** игрок получает сообщение о недоступности поиска, а команда продолжает в пределах оставшегося времени

### Requirement: Retrieved content is untrusted evidence
Текст внешних источников SHALL использоваться как справочные данные и не менять роли, лимиты, настройки или правила игры. Поиск SHALL обращаться только к фиксированным разрешённым адресам сервиса; произвольные URL из вопроса или модели SHALL не загружаться.

#### Scenario: Instructions in a retrieved snippet
- **WHEN** найденный фрагмент содержит просьбу изменить правила или раскрыть настройки
- **THEN** системные ограничения продолжают действовать, и фрагмент не предоставляет дополнительных полномочий
