# Проверка реализации

Проверена реализация изменения `simulate-chgk-team` на Python 3.13.12 с NiceGUI 3.17.1. Интерфейс использует Python-компоненты NiceGUI и CSS; исполнение команды — шесть отдельных узлов LangGraph.

## Автоматические проверки

| Проверка | Результат |
|---|---|
| `.venv/bin/python -m pytest -q` | 71 passed, 3 skipped; пропущены opt-in browser-тесты |
| Native NiceGUI user simulation | 5 тестов входят в успешный offline-прогон |
| Playwright / Chromium | 3 passed в отдельном browser-прогоне |
| Ruff check и format --check | Успешно |
| `openspec validate simulate-chgk-team --strict` | Успешно |
| `uv build --offline` | Собраны wheel и sdist |
| Содержимое wheel | Включены `web.py`, CSS и настройка SSL; отсутствуют прежние `app.js`, `index.html` и `.env` |

Тесты проверяют роли, передачу общей истории, полномочия капитана и эрудитов, версии, изоляцию сессий, поиск, финализацию, серверный дедлайн и отклонение поздних результатов. Проверены API, порядок и восстановление SSE, JSON-экспорт без credentials, отсутствие эталонов в запросах модели. Дополнительные проверки SSL охватывают оба имени настройки, окружение и dotenv, приоритет имён, включённую проверку по умолчанию и передачу `verify_ssl_certs=False` без CA bundle. Реальный конвертер схем установленного langchain-gigachat проверен offline для обычной реплики и финального ответа; fake-client тест проверяет выбор схемы и передачу `method="function_calling"`.

## Интерфейс в demo

Browser-прогон выполнен командой:

```sh
CHGK_BROWSER_TESTS=1 PLAYWRIGHT_BROWSERS_PATH=/tmp/chgk-team-browsers .venv/bin/python -m pytest -q tests/test_browser.py
```

Проверены ввод и запуск с клавиатуры, шесть карточек игроков, последовательные реплики, отклонённая и поддержанная версии, источник, ответ Софьи по назначению капитана, экспорт и новый вопрос. Проверены перезагрузка вкладки и временный разрыв соединения без повторного графа, сброса таймера и дублирования истории. Текст с HTML и скриптом отображается безопасно. На мобильной ширине 390 px горизонтального переполнения нет.

Скриншоты desktop/mobile просмотрены; сохранены в `artifacts/nicegui-desktop-idle.png`, `artifacts/nicegui-desktop-finished.png`, `artifacts/nicegui-mobile-finished.png`.

Demo-оценка двух учебных вопросов сохранена в `artifacts/demo-evaluation.json`: обе игры завершились с ответом, каждая содержит 10 реплик, 12 вызовов scripted-провайдера и один учебный поиск. Совпадение с эталоном — 1 из 2. Это фиксированный сценарий маятника Фуко, поэтому результат не измеряет качество GigaChat или способность решать произвольные вопросы.

## Ограниченный real smoke

Выполнена команда с доступом к сети:

```sh
UV_CACHE_DIR=/tmp/chgk-team-uv-cache uv run chgk-evaluate --mode real --limit 1 --output artifacts/real-smoke.json
```

Модель — `GigaChat-2-Max`, версия промптов — `2026-10-01.2`. Применена настройка пользователя `GIGACHAT__VERIFY_SSL=false`. После исправления ключа авторизация проходит. Структурированный ответ получается через штатный function calling в langchain-gigachat; инструкция вернуть JSON без этого механизма не обеспечивала корректного формата обычных реплик.

Финальный smoke завершился успешно:

| Показатель | Результат |
|---|---|
| Вопрос | Собственный учебный вопрос о приборе, демонстрирующем вращение Земли |
| Ответ | Маятник Фуко; совпал с допустимым эталоном |
| Длительность | 25.133 секунды, раннее решение капитана |
| Принятые реплики | 6; капитан, научный эрудит, логик, генератор идей |
| Вызовы модели | 11, включая один финальный |
| Успешные вызовы | 7; 6 обычных реплик и финальный ответ |
| Отклонённые ходы | 4 с кодом `invalid_reply`; состояние не изменено |
| Задержки вызовов | 1.392–2.778 секунды |
| Поиски | 0; модель не запросила поиск |
| Завершение | `answered`, отвечает капитан |

Просмотрена история: научный эрудит предложил маятник Фуко, логик сверил условия, капитан поддержал версию и запросил сомнения, генератор предложил метафорическое толкование, капитан отклонил его по формулировке вопроса и дал ответ. Принятая память и версии использовались в последующих ходах. Все шесть ролей получили вызовы, но эрудит-гуманитарий и интуит в этом прогоне не дали принятых реплик. Отчёт и экспорт сохранены в `artifacts/real-smoke.json` и каталоге `artifacts/real-smoke-transcripts/`.

Один учебный вопрос подтверждает работоспособность реального адаптера и обсуждения, но не оценивает точность на настоящем наборе ЧГК или устойчивую зрелищность. Четыре невалидных хода показывают, что модель может нарушать контракт и полномочия ролей даже со структурированным выводом: такие ходы отбрасываются. Реальный сетевой поиск в этом прогоне не использовался; его HTTP-контракт и деградация проверены offline, отображение — в demo. Полный платный benchmark не запускался.

## Публичные тексты и служебные поля

После просмотра пользовательского транскрипта `real_transcripts/chgk-b40a70c1-a770-48df-8270-759884c5e149.json` исправлено смешение речи с управлением графом. Модель помещала в `utterance` служебную очередь и готовность, а в версию и финальный ответ — фрагменты имён JSON-полей. Экспорт лишь сохранял эти значения.

Версия промптов `2026-10-01.3` разделяет естественную речь и служебные аргументы, передаёт имена коллег в составе и использует описания полей function calling вместо дублирования полного JSON Schema в системном промпте. Валидатор публичных текстов отклоняет явные служебные сводки и сериализованные поля. Регрессионные тесты воспроизводят исходные дефекты в репликах, версиях, причинах и финальном ответе; отдельно проверено, что чистая капитанская реплика сохраняется вместе с очередью, делегированием и готовностью, а загрязнённая не попадает в историю или экспорт.

Повторный реальный прогон того же вопроса сохранён в `artifacts/public-text-smoke.json`: 33.775 секунды, 13 принятых реплик, 17 вызовов, три отклонённых хода `invalid_reply`, финальный ответ «температура», отвечает Софья. Все 20 публичных текстовых полей просмотрены и прошли валидацию; служебных сводок и фрагментов JSON в них нет. Исходный пользовательский транскрипт не изменён. Этот прогон проверяет устранение смешения текста и управления, без оценки точности ответа по внешнему эталону.
